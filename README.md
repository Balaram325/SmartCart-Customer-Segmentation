# 🛒 SmartCart Customer Segmentation System

## 📌 Project Overview
SmartCart is an e-commerce platform aiming to improve marketing efficiency 
by identifying meaningful customer segments using clustering algorithms.

This project applies Unsupervised Machine Learning techniques to segment
customers based on purchasing behaviour, engagement levels, and loyalty indicators.

---

## 📊 Dataset Information
- 2240 Customers
- 22 Features
- Demographics
- Purchase Amount
- Purchase Frequency
- Customer Feedback

---

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

---

## 🧠 Algorithms Applied
- KMeans Clustering
- Hierarchical Clustering

---

## 🎯 Business Objective
To group customers into meaningful clusters that help:
- Personalized marketing
- Customer retention
- Targeted promotions
- Data-driven decision making

---

## 📈 Project Outcome
Identified customer segments based on spending patterns
and engagement behaviour, enabling smarter marketing strategies.
